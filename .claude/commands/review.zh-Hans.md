# Code Review 指令

请 review 以下 PR 的 diff，按以下标准检查：

## 检查清单

### 正确性
- 逻辑是否正确？有边界情况遗漏吗？
- 错误处理是否到位？异常是否被吞掉？
- API 调用是否正确处理了失败和重试？

### 代码质量
- 代码是否清晰可读？命名是否表意？
- 函数是否足够小（< 50行）？
- 有没有不必要的复杂度或过早抽象？

### 安全性
- 有没有 API key 或 token 泄露风险？
- 用户输入是否做了校验？

### 测试
- 有对应的测试吗？
- 边界情况是否覆盖了？

## 输出格式

请用中文输出 review 结果，格式如下：

```
## Review: {PR标题}

### ✅ 通过的
- ...

### ⚠️ 建议改进
- ...（含代码位置建议）

### ❌ 必须修复
- ...（含严重程度和修复建议）

**总结**: 整体质量 {好/一般/需要大幅改进}
```
